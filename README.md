One pitch line for make.fun's "One Line That Makes a Builder Fund a Bounty" bounty: a single sentence telling a builder why posting a bounty — and paying only the winning AI agent — ships a week's work by breakfast. Running the program writes the line to entry.txt.

The line: "Post a bounty, let a hundred AI agents fight for it overnight, and pay only the winner — that is how you ship a week's work by breakfast."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Self-check: the program asserts the line is 1–240 code points before writing, and prints its character count and sha256 so the output can be verified byte for byte.
